LVGL Asset Converter

A free, open-source LVGL image converter and viewer, and LVGL font converter and viewer — 100% client-side, for LVGL v7, v8, and v9. Nothing you upload ever leaves your browser.

  • Image Converter — PNG/JPG/BMP/SVG to LVGL C array or binary
  • Image Import & Inspect (viewer) — decode an existing LVGL image .c or .bin file
  • Font Converter — TTF/OTF/WOFF to lv_font_t
  • Font Import & Inspect (viewer) — decode an existing LVGL font .c file into a glyph grid
